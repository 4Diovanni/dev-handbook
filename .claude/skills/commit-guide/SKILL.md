# Commit guide

## Format

```text
<type>(<optional scope>): <imperative summary, lower case, no period, max 72 chars>

<body: why the change was made, wrapped at 72 chars, optional>

<footer: BREAKING CHANGE: ..., Refs: #123, optional>
```

Types: `feat`, `fix`, `docs`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`. Use `!` after the type for breaking changes (`feat!:`).

## Hard rules

- Write the message in English.
- Never add AI attribution: no `Co-Authored-By` lines for AI tools, no session links, no "Generated with" or "Generated by" lines, no emoji banners. This applies to commits, PR titles, PR bodies and review comments.
- One logical change per commit. Do not mix formatting with behavior changes.
- If the repository has `scripts/check_ai_attribution.py`, run it on the message before committing: `python3 scripts/check_ai_attribution.py --text "<message>"`.
- Never commit or push unless the user asked for it.
